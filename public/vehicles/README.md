# Vehicle images

Drop an image named after the vehicle here and it replaces the drawn silhouette
on every listing that flies it. No seeding step — the server picks up whatever
is in this folder at start-up.

Naming: lower-case the vehicle name exactly as it is listed, spaces to hyphens.

    Falcon 9         -> falcon-9.png
    Electron         -> electron.png
    Vega-C           -> vega-c.png
    KSLV-II (Nuri)   -> kslv-ii-nuri.png
    RFA One          -> rfa-one.png

`.png`, `.webp` and `.svg` work. Transparent backgrounds look best — the image
is letterboxed into a tall, narrow box beside the card, so a vertical shot of
the vehicle fits the space and a wide one will look small.

Where to get them: most launch companies publish a press or media kit with
images and usage terms. Read the terms — they usually allow editorial use and
restrict anything implying endorsement, which a marketplace listing arguably
does. For the providers that matter to you, asking permission is a short email
and starts a useful conversation.

Do not take them from another company's product. Nothing in this folder is
committed to the repo.
